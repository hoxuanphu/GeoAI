Plan cụ thể hóa spec thành task để AI/dev thực hiện; plan được viết và kiểm không đồng nghĩa task code đã chạy. Các quyết định kỹ thuật và gate tiếp tục theo spec/ADR, trạng thái tại [tracker](../../task-tracker.md).

| Plan | Đầu vào | Cách đọc | Trạng thái |
